Pop Launcher Privacy Policy

How Pop Launcher handles information on your device, respects permissions, and interacts with remote services.

Effective date: October 2026

1. Core Principles & Architecture

Pop Launcher is a high-performance, distraction-free home-screen launcher for Android devices. It is designed from the ground up with a local-first, privacy-by-design architecture.

Pop Launcher:

  • Does not operate user accounts or require sign-up.
  • Does not include advertising networks, tracking libraries, or marketing analytics SDKs.
  • Does not upload your installed applications, contacts, photos, files, or usage statistics to any Pop Launcher server.
  • Does not sell, rent, or monetize your personal information.

2. Installed Applications & Package Visibility

android.permission.QUERY_ALL_PACKAGES

As an Android home-screen launcher replacement, Pop Launcher requires access to query installed packages on your device. This permission is strictly required to:

  • Display installed apps on the home screen, floating bubbles, and application drawer.
  • Perform instantaneous local app search and launch activities.
  • Manage user-configured app friction timers and custom app groupings.

Installed-app metadata (package names, app labels, launchable activities, and icons) is read and maintained purely in active device memory. It is never transmitted off your device.

3. Photos, Media & Document Search

READ_MEDIA_IMAGES · READ_MEDIA_VIDEO · READ_MEDIA_AUDIO · READ_EXTERNAL_STORAGE

Pop Launcher provides an optional, on-device media and file search feature. If you enable the Media or File search providers, the launcher requests permission to access:

  • Photos and images (READ_MEDIA_IMAGES, READ_MEDIA_VISUAL_USER_SELECTED).
  • Videos (READ_MEDIA_VIDEO).
  • Audio files (READ_MEDIA_AUDIO).
  • Scoped device storage and documents on supported Android versions.

Strict Local Processing: File and media indexing is executed entirely on your device via standard Android MediaStore and scoped storage APIs. Your photos, videos, audio recordings, documents, and thumbnail previews are never uploaded, analyzed by cloud servers, or transmitted to any remote destination. You may grant or revoke media access at any time in Android System Settings, or disable the Media and File search providers inside Pop Launcher Settings.

4. Contacts & People Search

android.permission.READ_CONTACTS

Pop Launcher offers an optional People search provider. Android Contacts permission is requested only after you deliberately choose to enable People search.

Contact names, phone numbers, and avatars are processed entirely on-device to present quick search matches and direct-dial / SMS shortcuts. Contact data is never uploaded, synced to any external service, or stored outside standard Android contacts providers. You can revoke Contacts permission at any time in Android System Settings.

5. Android 15 Private Space & Hidden Profiles

android.permission.ACCESS_HIDDEN_PROFILES

On devices running Android 15 and higher, Pop Launcher supports Android's native Private Space. This permission allows the launcher to display protected applications only when your Private Space profile is unlocked through Android system authentication (such as fingerprint or screen lock).

Private Space profile states and contents are protected by Android system isolation and are never logged, exported, or shared off-device.

6. Search, Web Queries & AI Overview

By default, search is performed entirely on your device across local apps, contacts, and files.

Web Search & AI Overview:

  • Web search and AI overview features are strictly optional and opt-in.
  • When you explicitly trigger a web query or enable AI overviews, only the specific search query string you typed is transmitted over secure HTTPS to the selected provider (such as DuckDuckGo or a user-configured Gemini API endpoint).
  • Search queries are never accompanied by personal identifiers, contact lists, device IDs, or installed app inventories.
  • Pop Launcher does not retain query logs or use user searches to train artificial intelligence models.

7. Custom Widgets & Mini Applets

Pop Launcher supports an optional catalog of interactive mini applets and custom widgets published by the creator.

  • Catalog Manifest: The app retrieves a creator-controlled JSON manifest over secure HTTPS from GitHub Pages. The manifest contains structured, declarative layout definitions, versions, and descriptions.
  • No Remote Code Execution: Mini applets do not download, execute, or interpret arbitrary binary code or external executable scripts. All UI elements render natively through a sandboxed client-side parser.
  • API Actions: If a custom widget includes a public data fetch action (e.g., retrieving public weather forecasts or exchange rates via FETCH_API), requests are sent directly from your device to the specified public API over HTTPS without transmitting personal identifying data.
  • Explicit User Choice: No custom widgets are installed automatically. Widgets are stored locally on your device only when you explicitly tap Add, and can be removed at any time.

8. Data Retention, Storage & Deletion

Information stored locally on your device includes:

  • User settings (accent color, physics toggles, enabled search providers).
  • Locally cached search ranking affinities (recent query-to-selection pairings to prioritize frequent results).
  • Local state and configuration of installed custom widgets.

How to delete your data:

  • In-app: Go to Pop Launcher Settings → Privacy & Data Use → Clear Search History to erase all search ranking data.
  • System-wide: Clear app storage via Android Settings → Apps → Pop Launcher → Storage → Clear Data or simply uninstall the application. All local configuration and caches will be permanently erased.
  • Because Pop Launcher does not store data on cloud servers, no server-side data retention or deletion request is necessary.

9. Changes to this Policy

If we update Pop Launcher's data practices or introduce new features affecting your privacy, we will update this policy along with the effective date at the top of this document. Continued use of Pop Launcher constitutes acceptance of any updated policy.
